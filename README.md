# TutorHub — ห้องติวสอบ

เว็บสรุปเนื้อหาและฝึกทำข้อสอบสำหรับนักศึกษา DTI มหาวิทยาลัยธรรมศาสตร์ ศูนย์ลำปาง อ่านเนื้อหา ทบทวนก่อนสอบ ทำแบบฝึกหัด และดูหัวข้อเก็งสอบได้ในที่เดียว

เปิดเว็บ: **[thanatvij.github.io/TutorHub](https://thanatvij.github.io/TutorHub/)**

## วิชาในเว็บ

| วิชา | เนื้อหา | แบบฝึกหัด |
|---|---|---|
| **DTI232** ระเบียบวิธีเชิงลำดับขั้นตอนและการค้นหาอย่างชาญฉลาด | เว็บไซต์ติวกลางภาคเดิม รวมบทเรียนและภาพอธิบายแบบโต้ตอบ | แบบฝึกและเครื่องมือทบทวนเดิม |
| **DTI286** โหมดของประสบการณ์มนุษย์ (Modes of Human Experience) | บทอ่านครบ 4 บท ตามเอกสารประกอบการสอน | 29 รายการตามใบงานแนวทบทวน |
| **PB287** การเตรียมความพร้อมและการตอบโต้ภัยพิบัติ | บทอ่านสัปดาห์ที่ 1–7 | ข้อปรนัยจำลอง 70 ข้อ |

แต่ละวิชามี 4 โหมด:

- **ติวสอบ** — วันเวลา ขอบเขต และข้อมูลที่ยืนยันจากเอกสาร
- **ติวเนื้อหา** — บทอ่านเต็มพร้อมสารบัญและเช็กลิสต์
- **แบบฝึกหัด** — ตรวจคะแนนข้อปรนัยและแสดงแนวคำตอบข้อเขียน
- **เก็งข้อสอบ** — จัดลำดับหัวข้อจากหลักฐานในเอกสารประกอบการสอน ไม่ใช่ข้อสอบจริง

## แหล่งเนื้อหา

เนื้อหาสรุปจากเอกสารคำสอน สไลด์ และแนวทบทวนที่ได้รับ โดยระบุชื่อไฟล์ต้นทางท้ายแต่ละบทเพื่อให้ตรวจย้อนกลับได้ เอกสารต้นฉบับ หนังสือ และสไลด์ของอาจารย์ไม่ได้อัปโหลดไว้ใน public repository นี้

## เปิดใช้งานบนเครื่อง

ดาวน์โหลดหรือ clone repository แล้วเปิด `index.html` ได้ทันที หรือใช้ไฟล์เริ่มต้นตามระบบปฏิบัติการ:

- macOS: `start-mac.command`
- Windows: `start-windows.bat`

ความคืบหน้า หัวข้อที่อ่านแล้ว และคำตอบแบบฝึกหัดจะเก็บในเบราว์เซอร์ของผู้ใช้ แยกตามแต่ละวิชา

## โครงสร้างหลัก

```text
TutorHub/
├── index.html          # หน้าเลือกวิชา
├── subject.html        # หน้าติว DTI286 และ PB287
├── data/               # เนื้อหาและโจทย์ของแต่ละวิชา
├── shared/             # รูปแบบหน้าเว็บและระบบแบบฝึกหัด
├── dti232/             # เว็บไซต์ DTI232 เดิม
└── fonts/              # ฟอนต์ที่ใช้ภายในเว็บ
```

เว็บเผยแพร่ผ่าน GitHub Pages จาก branch `main` ที่โฟลเดอร์รากของ repository
