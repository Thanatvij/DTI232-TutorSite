# DTI232 ติวสอบกลางภาค — เว็บติวออนไลน์

เว็บสำหรับติวสอบกลางภาค DTI232 ใช้งานผ่าน GitHub Pages ได้โดยตรง ไม่ต้องดาวน์โหลดหรือเปิดไฟล์ในเครื่อง

## 🌐 เข้าใช้งาน

เปิดลิงก์ GitHub Pages ของเว็บ

สามารถเข้าบางส่วนของเว็บโดยตรงได้ เช่น:

- `.../dti232-tutor/#p3` → ส่วนที่ 3
- `.../dti232-tutor/a4.html` → กระดาษ A4 เข้าห้องสอบ

> แนะนำให้ใช้ **Chrome หรือ Edge** เพื่อให้การทำงานของเว็บและการพิมพ์ A4 ตรงที่สุด

## 📚 เนื้อหาที่มีในเว็บ

ทุกอย่างสามารถใช้งานผ่านเว็บได้ทันที:

- BFS
- Merge Sort
- Binary Search
- Karatsuba
- เครื่องคำนวณ Big-O
- ชุดฝึก
- VisuAlgo
- กระดาษ A4 สำหรับเข้าห้องสอบ

### VisuAlgo

แท็บ **VisuAlgo** ต้องเชื่อมต่ออินเทอร์เน็ต

หากกรอบ VisuAlgo ไม่แสดง ให้กด **"เปิดในแท็บใหม่"**

ส่วนเครื่องมืออื่น ๆ สามารถใช้งานได้โดยไม่ต้องพึ่งอินเทอร์เน็ต

## 📝 กระดาษ A4 เข้าห้องสอบ

เข้าได้จาก `a4.html` หรือกดปุ่มกระดาษ A4 จากหน้าแรกของเว็บ

### การแก้ไข

- คลิกที่ข้อความเพื่อแก้ไขได้ทันที
- ระบบจะจำการแก้ไขไว้ในเบราว์เซอร์โดยอัตโนมัติ
- หากต้องการเก็บไฟล์ที่แก้ไขแล้ว ให้กด **"บันทึกไฟล์ที่แก้แล้ว"**

### ถ้าแก้แล้วเนื้อหาล้นหน้า

หากเนื้อหาล้น จะมีขีดแดงใต้คอลัมน์

กด **"ปรับให้เต็มพอดีหน้า"**

ระบบจะปรับขนาดตัวอักษรให้ใหญ่ที่สุดเท่าที่จะยังพอดีกับแต่ละคอลัมน์

### 🖨️ การพิมพ์ / บันทึก PDF

กด **"พิมพ์ / บันทึก PDF"** แล้วตั้งค่า:

- กระดาษ: **A4**
- แนวกระดาษ: **แนวนอน (Landscape)**
- ระยะขอบ: **ไม่มี (None)**
- Scale: **100%**
- เปิด **Background graphics**
- พิมพ์สองหน้า: **พลิกด้านสั้น (Short Edge)**

> แนะนำให้ใช้ **Chrome หรือ Edge**

## ⚠️ หมายเหตุ

- การแก้ไข `a4.html` จะถูกเก็บไว้ในเบราว์เซอร์ของแต่ละคน
- การแก้ไขของคนหนึ่งจะ **ไม่กระทบคนอื่น**
- หากแชร์ Repository เป็น **Public** ทุกคนสามารถมองเห็นไฟล์ภายใน Repository ได้
