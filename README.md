DTI232 ติวสอบกลางภาค — เว็บรันบนเครื่องตัวเอง

วิธีเปิด (เลือกอย่างใดอย่างหนึ่ง)
1) ง่ายสุด: ดับเบิลคลิก index.html  → ใช้งานได้ทุกเครื่องมือแบบออฟไลน์
2) แบบ localhost:
   - Mac: ดับเบิลคลิก start-mac.command
     (ครั้งแรกถ้า macOS เตือน ให้คลิกขวา > Open) หรือใน Terminal:
       cd โฟลเดอร์นี้ ; python3 -m http.server 8232   แล้วเปิด http://localhost:8232
   - Windows: ดับเบิลคลิก start-windows.bat (ต้องมี Python)

แท็บ VisuAlgo ต้องต่ออินเทอร์เน็ต ถ้ากรอบว่างให้กด "เปิดในแท็บใหม่"
ทุกอย่างอื่น (BFS, Merge Sort, Binary Search, Karatsuba, เครื่องคำนวณ Big-O, ชุดฝึก) ทำงานออฟไลน์

Karatsuba แบบแอนิเมชัน
- หน้าเริ่มด้วยตัวอย่าง 12 × 56 เพื่อให้เห็นวงจร P → Q → R → S → M ก่อน
- กด "เล่น" เพื่อให้เดินอัตโนมัติ หรือใช้ "ย้อน / ขั้นถัดไป / ข้ามไปจบ"
- แถบ 5 ขั้นบอกว่ากำลังผ่าเลข หา P หา Q หา R/S หรือประกอบ M
- ต้นไม้การเรียกซ้ำใช้สีเหลืองแทนงานปัจจุบัน และสีเขียวแทนค่าที่คำนวณเสร็จแล้ว
- เปิด "ตารางทุกการเรียก" เมื่อต้องการฝึกเขียนคำตอบลงกระดาษ

แชร์ให้เพื่อน: ส่งทั้งโฟลเดอร์ (หรือไฟล์ zip) — ต้องมีโฟลเดอร์ fonts อยู่ข้าง index.html

กระดาษ A4 เข้าห้องสอบ (a4.html)
- เปิด a4.html (หรือกดปุ่มในหน้าแรกของเว็บ) → คลิกที่ข้อความเพื่อแก้ไขได้ทันที
- ระบบจำการแก้ไขไว้ในเบราว์เซอร์อัตโนมัติ · ปุ่ม "บันทึกไฟล์ที่แก้แล้ว" ดาวน์โหลดเก็บเป็นไฟล์ใหม่ (วางไว้ในโฟลเดอร์เดียวกับ fonts)
- ถ้าแก้แล้วล้นหน้า จะมีขีดแดงใต้คอลัมน์ → กด "ปรับให้เต็มพอดีหน้า" ระบบจะหาขนาดตัวอักษรที่ใหญ่ที่สุดที่ยังพอดีให้แต่ละคอลัมน์
- กด "พิมพ์ / บันทึก PDF" → เลือกกระดาษ A4 แนวนอน · ระยะขอบ: ไม่มี (None) · Scale 100% · เปิด "Background graphics" · พิมพ์สองหน้าแบบพลิกด้านสั้น
- ใช้ Chrome หรือ Edge จะได้ผลตรงที่สุด

แชร์ให้เพื่อนผ่าน GitHub Pages (ฟรี)
1) สมัคร/ล็อกอิน github.com → New repository → ตั้งชื่อ เช่น dti232-tutor → Public → Create
2) หน้า repo → "uploading an existing file" → ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป
   (index.html, app.js, a4.html, .nojekyll, README.txt, start-*.* และโฟลเดอร์ fonts ทั้งโฟลเดอร์) → Commit changes
   * index.html ต้องอยู่ชั้นนอกสุดของ repo ไม่ใช่อยู่ในโฟลเดอร์ย่อย
3) Settings → Pages → Source: Deploy from a branch → Branch: main / (root) → Save
4) รอ 1–2 นาที ลิงก์จะเป็น https://ชื่อผู้ใช้.github.io/dti232-tutor/
   ส่งลิงก์ตรงแท็บได้ เช่น …/dti232-tutor/#p3 (ส่วน 3) หรือ …/a4.html
ข้อควรระวัง: repo แบบ Public ทุกคนเห็นได้ อย่าอัปโหลดไฟล์หนังสือ สไลด์ หรือเอกสารของอาจารย์ขึ้นไปด้วย
การแก้ไข a4.html บนเว็บจะเก็บในเบราว์เซอร์ของแต่ละคน ไม่กระทบคนอื่น
