BFS-MATRIX(A, n, s)

 1 FOR i ← 1 TO n  visited[i] ← 0
 2 Q ← คิวว่าง ; visited[s] ← 1 ; d[s] ← 0 ; ใส่ s เข้า Q
 3 WHILE Q ไม่ว่าง
 4    u ← DEQUEUE(Q) ; OUTPUT u
 5    FOR v ← 1 TO n                      (List: FOR v ในรายการของ u)
 6       IF A[u][v] = 1 AND visited[v] = 0
 7          visited[v] ← 1 ; d[v] ← d[u] + 1 ; parent[v] ← u ; ใส่ v เข้า Q
