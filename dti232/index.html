DTI232 ติวกลางภาค

สอบอังคาร 22 ก.ย. 2569 · 13.00–15.00

ข้อเขียน 4 ส่วน 100 คะแนน เนื้อหาสัปดาห์ 1–4 จบที่ BFS กดการ์ดเพื่อไปยังเครื่องมือของแต่ละส่วน

กติกาข้อ 5 บนปกข้อสอบ: ทุกส่วนเริ่มจากสถานการณ์จริง ให้ตอบความหมายของปัญหาเป็นภาษาธรรมดาก่อน แล้วจึงใช้สัญลักษณ์หรือชื่ออัลกอริทึม
ประโยคเปิด: "ปัญหานี้คือการ ___ เพื่อให้ ___ โดยมีข้อจำกัดว่า ___" แล้วแยก สิ่งที่เห็น / กลไก / เป้าหมาย

เอาอะไรเข้าห้องได้

หนังสือประจำวิชา 1 เล่ม + กระดาษโน้ต A4 ไม่เกิน 2 หน้า (1 แผ่นหน้า-หลัง ติดหรือเย็บในหนังสือก่อนเข้าห้อง) + Post-it ไม่จำกัด (ติดในหนังสือ) · ห้ามสมุด กระดาษแยก หนังสืออื่น และอุปกรณ์อิเล็กทรอนิกส์

เปิดกระดาษ A4 เข้าห้องสอบ (แก้ไขได้ + พิมพ์เป็น PDF)

ลำดับการเขียนคำตอบทุกข้อ

  1. อธิบายความหมายของปัญหาเป็นภาษาธรรมดา
  2. ข้อมูลนำเข้า ผลลัพธ์ ข้อจำกัด กรณีขอบเขต พฤติกรรมที่คาดหวัง
  3. วิธีแทนข้อมูลและโครงสร้างข้อมูล พร้อมเหตุผล
  4. ขั้นตอนวิธี (ซูโดโค้ดมีเลขบรรทัด หรือข้อความทีละขั้น)
  5. ไล่ตัวอย่างเล็กเป็นตาราง
  6. บิกโอของเวลาและพื้นที่ บอกว่านับอะไรเป็น 1 หน่วย (แบบจำลองแรม)
  7. ตรวจด้วย 3E และคำแนะนำแบบมีเงื่อนไข

ส่วน 1 · จากงานจริงสู่ Input และ Output

อ่านสถานการณ์ ลองเขียนคำตอบบนกระดาษก่อน แล้วค่อยเปิดดูตัวอย่างคำตอบ

แม่แบบ (แบบหนังสือหน้า 15)

Input : กำหนดให้ C เป็นเซตของ ___ โดยที่ C = {c1, c2, …, cN} และ ci = (รหัส, ___, ___)
Output: ___ โดยที่ ___          เช่น C' = {c'1 ≤ c'2 ≤ … ≤ c'N}  หรือ  "ตำแหน่ง / null"
Constraints: ขนาดสูงสุด · ความจุ · ทรัพยากรที่ใช้พร้อมกันได้
Edge cases : ไม่มีข้อมูล · มี 1 ตัว · ซ้ำหมด · ติดลบหมด · ไม่พบ · เกินความจุ
Expected   : ต้องจบการทำงาน · ไม่มีข้อมูลหาย/ซ้ำ

ส่วน 2 · แบ่งแยกและเอาชนะ

แบ่ง → แก้ย่อยจนถึงกรณีฐาน → รวม · ใส่ข้อมูลเองได้ทุกเครื่องมือ

Merge Sort แบบแอนิเมชัน

ส่วนซ้ายส่วนขวากำลังเทียบรวมเสร็จ/เรียงแล้ว

Merge Sort แบบเขียนเป็นข้อความ ห้ามวาดรูป (Task 2) 
Input : C = c1, …, cN ที่ยังไม่เรียง       Output: C' โดยที่ c'1 ≤ c'2 ≤ … ≤ c'N
ขั้นที่ 1 แบ่ง C เป็น C_left = c1…c⌊N/2⌋ และ C_right = c⌊N/2⌋+1…cN
ขั้นที่ 2 ทำขั้นที่ 1 ซ้ำกับแต่ละส่วนจนเหลือข้อมูล 1 ตัว (1 ตัวถือว่าเรียงแล้ว = กรณีฐาน)
ขั้นที่ 3 รวมสองส่วนที่เรียงแล้ว: ตั้ง i = 1, j = 1
          ถ้า C_left[i] ≤ C_right[j] ต่อ C_left[i] ท้ายผลลัพธ์ แล้ว i = i + 1
          มิฉะนั้น ต่อ C_right[j] ท้ายผลลัพธ์ แล้ว j = j + 1
          เมื่อส่วนใดหมด ต่อข้อมูลที่เหลือของอีกส่วนทั้งหมดท้ายผลลัพธ์
ขั้นที่ 4 ทำขั้นที่ 3 กับคู่ที่แบ่งมาจากส่วนเดียวกัน จากเล็กไปใหญ่ จนเหลือลำดับเดียว

    Binary Search บนผลลัพธ์ที่เรียงแล้ว

    Karatsuba ทุกการเรียกซ้ำ

    ความหมาย + ซูโดโค้ด 
    ผ่าเลข X = a·10^k + b , Y = c·10^k + d
XY = ac·10^2k + (ad+bc)·10^k + bd       ← ต้องคูณ 4 ครั้ง
แต่ ad+bc = (a+b)(c+d) − ac − bd        ← เหลือ 3 ครั้ง: P=ac  Q=bd  R=(a+b)(c+d)

KARATSUBA(X, Y)
 1. n ← จำนวนหลักของ X          2. m ← จำนวนหลักของ Y
    ถ้า n = 1 หรือ m = 1 ให้ return X × Y        ← กรณีฐาน
 3. k ← ceil(max(n, m) / 2)
 4. a ← floor(X / 10^k)          5. b ← X mod 10^k
 6. c ← floor(Y / 10^k)          7. d ← Y mod 10^k
 8. P ← KARATSUBA(a, c)          9. Q ← KARATSUBA(b, d)
10. R ← KARATSUBA(a+b, c+d)     11. S ← R − P − Q
12. M ← P × 10^(2k) + S × 10^k + Q            13. return M
T(n) = 3T(n/2) + Θ(n) = Θ(n^1.585)   (คูณแบบตั้งหลัก Θ(n²))
